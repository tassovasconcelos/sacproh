# Guia do usuário

1. Entre pelo link recebido e defina uma senha individual; nunca compartilhe credenciais.
2. Cadastre clientes, produtos, transportadoras e responsáveis somente com dados necessários ao atendimento.
3. Abra o SAC com descrição objetiva, nota fiscal, produto, lote, série, validade e evidências disponíveis.
4. Classifique prioridade, risco ao usuário e evento adverso com cuidado; casos sensíveis exigem escalonamento imediato.
5. Registre cada contato, decisão, alteração de status, coleta, análise técnica e solução.
6. Abra ordem de serviço quando houver avaliação técnica, peças, custo ou teste de bancada.
7. Encerre somente com parecer, procedência, solução e evidências completas.

Dados incorretos devem ser corrigidos pela função apropriada, preservando a auditoria. Suspeitas de vazamento ou acesso indevido devem ser comunicadas imediatamente ao administrador.
